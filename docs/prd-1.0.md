# PRD 1.0

## 제품 개요

- 제품명: Blogle2
- 제품 유형: 검증된 AI 앱 개발자 매칭 플랫폼
- 1차 고객: AI 프로젝트를 처음 발주해보는 스타트업 CTO 또는 개발팀장
- 핵심 방향: 말이나 이력서가 아니라 과제 기반 결과로 AI 구현 실력을 검증한 개발자를 추천한다.

## 문제 정의

AI 프로젝트를 발주하려는 스타트업 CTO는 검증할 기준도 내부 전문가도 없는 상황에서 AI 앱 개발자를 골라야 한다. 지원자 포트폴리오와 면접만으로는 실제 구현 실력을 판단하기 어렵기 때문에, 잘못 뽑아 시간과 비용을 낭비할까 봐 채용 결정을 내리지 못하고 프로젝트가 지연된다.

## 핵심 가치

- 기업이 검증된 AI 앱 개발자를 빠르게 찾게 한다.
- 잘못된 채용으로 생기는 시간과 비용 낭비를 줄인다.
- 기업이 AI 프로젝트를 안심하고 맡길 수 있게 한다.

## MVP 범위

### 1. 프로젝트 조건 입력과 인재 추천

- 기업이 AI 기능 유형, 기간, 예산 등 프로젝트 조건을 입력한다.
- 조건에 맞는 검증 개발자 추천 목록을 즉시 확인한다.
- 상위 후보 2~3명의 프로필을 비교한 뒤 매칭을 신청한다.

### 2. 개발자 검증 프로필

- 개발자의 과제 기반 인증 배지를 보여준다.
- 실력 점수와 프로젝트 이력을 함께 보여준다.
- 기업이 이력서보다 검증 결과를 중심으로 판단하게 한다.

### 3. 성사 보증 안내

- 중도 이탈 시 대체 개발자 보장 정책을 안내한다.
- 계약 전 기업이 보증 조건을 확인할 수 있게 한다.
- 프로젝트 진행 중 문제 발생 시 중재 요청 흐름을 준비한다.

## 첫 사용 시나리오

1. 스타트업 CTO가 플랫폼에 접속한다.
2. AI 기능 종류, 기간, 예산 등 프로젝트 조건을 입력한다.
3. 검증 배지 보유 개발자 추천 목록을 확인한다.
4. 상위 후보의 프로필, 실력 점수, 프로젝트 이력을 비교한다.
5. 원하는 후보에게 매칭을 신청한다.
6. 매칭 결과를 이메일 또는 문자로 받는다.

## 이번 버전에서 제외할 것

- 리뷰·평점 시스템
- 개발자 셀프 지원 공고
- 커뮤니티 기능
- 결제 시스템
- 채팅 기능
- 구직자 포럼
- SNS 공유·바이럴 기능
- 개발자 자기계발 콘텐츠
- 기업 직접 공고 게재

## 역할 기준

- 지원자: 개발자 프로필과 검증 결과의 대상
- 채용담당자: 프로젝트 조건을 입력하고 추천 개발자를 확인하는 기업 사용자
- 면접관: 추후 검증·평가 플로우에 연결될 수 있는 역할

역할 값과 데이터 이름은 `docs/data-guide.md`를 따른다.

## 디자인 기준

- 레퍼런스: Toptal
- 분위기: 단단한 업무 도구
- 메인 컬러: 레드 계열
- 핵심 원칙: 직관적이고 단순하며 높은 가독성
- 피할 것: 너무 많은 이미지 사용
- 운영 방식: 최소 기준을 맞추고, 약한 불일치는 후속 정리한다.

세부 화면 기준은 `docs/design-system.md`를 따른다.

## 데이터 기준

- 새 컬렉션, 필드, 상태값, 역할 값은 구현 전 `docs/data-guide.md`의 공통 이름 사전을 먼저 확인한다.
- 기존 이름과 의미가 같으면 새 이름을 만들지 않는다.
- 필요한 이름이 없으면 사전에 먼저 추가한 뒤 구현한다.

## Firebase 기준

- Firebase SDK 값은 `.env`에만 저장한다.
- SDK 값은 문서에 기록하지 않는다.
- 현재는 Hosting 중심으로 사용한다.
- Firestore, Storage는 필요 시 `docs/firebase-guide.md` 기준에 따라 추가한다.

## 협업 기준

- 팀장: 안시영
- AI는 코드 수정, 문서 수정, 실행 확인, 빌드 확인, 커밋, PR 생성을 수행한다.
- 팀장은 PR 최종 병합과 배포를 담당한다.
- 파일 삭제, 대규모 이동, 의존성 추가, 공통 구조 변경은 AI가 먼저 물어본다.
- 작업 브랜치는 `student/이름/작업명` 형식을 기본으로 한다.

## 성공 기준

- 기업 사용자가 프로젝트 조건 입력 후 추천 개발자 목록을 이해할 수 있다.
- 개발자 프로필에서 인증 배지, 실력 점수, 프로젝트 이력을 확인할 수 있다.
- 기업 사용자가 매칭 신청까지 막힘 없이 진행할 수 있다.
- 화면은 단단한 업무 도구 톤과 높은 가독성을 유지한다.
- 새 데이터 이름은 공통 이름 사전을 거친다.
